# Mohammed Mohtashim Ibaad – Portfolio

React + Vite portfolio.

## Run locally
```
npm install
npm run dev
```

## Customise
Everything lives in `src/data.js`. Replace the `YOUR-USERNAME` GitHub/LinkedIn links and each project's `live` / `code` links (a `"#"` link is hidden automatically).

## Deploy
Push to GitHub, then import the repo on vercel.com. Vercel auto-detects Vite (build: `npm run build`, output: `dist`).
